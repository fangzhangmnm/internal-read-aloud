- 「`that the reasons of the confederacy were these--first, ` --没断句」 → 破折号 / 双连字符断点。
- 「再给你个例子 … `<s><|e1v3|>一个信使满头大汗，一边跑一边大喊：“好消息！坏消息！快来看啊！”他在人群中转圈乱跑，大声喊着：“拿撒勒人耶稣被抓了！拿撒勒人耶稣被抓了！”`」 → 引出语 + 三连感叹 + 引号后接着说；开头的机器记号不念。
- 「以及护栏一下碰到长公式code latex的时候不会被断的支离破碎的情况」 → 整块公式 / 代码不念不切，行内的不在里面断。
